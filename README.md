# Webinars Bulldozer — Dashboard pipeline

Dashboard de suivi des webinars Bulldozer : métriques LinkedIn (snapshot au 23/09/2026) + pipeline HubSpot live par liste d'inscrits.

- Ouvrir `index.html` dans un navigateur : les métriques LinkedIn s'affichent.
- Le pipeline HubSpot et la répartition par tier ne se chargent que dans claude.ai (connecteur HubSpot). Hors claude.ai, un bandeau l'indique.
